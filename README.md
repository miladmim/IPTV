# پرتو TV — نسخه‌ی استاتیک و بدون سرور (Zero-PHP)

پرتو TV یک وب‌اپلیکیشن فوق‌العاده سریع و شبیه به «رسیور ماهواره‌ای» در مرورگر است که **۱۰۰٪ بدون PHP، بدون دیتابیس و بدون نیاز به هاست و دامین** اجرا می‌شود.

این پروژه برای استقرار کاملاً رایگان روی **GitHub Pages** و **GitLab Pages** یا اجرای محلی طراحی شده است.

---

## 🌟 ویژگی‌های کلیدی

- **بدون PHP و سرور:** تمام منطق برنامه، تحلیل‌ها، فیلترها و پخش ویدیو به صورت کلاینت‌ساید (Client-Side) با جاوااسکریپت خام اجرا می‌شود.
- **رایگان همیشگی بدون هاست و دامنه:** قابل راه‌اندازی با یک کلیک روی **GitHub Pages** یا **GitLab Pages**.
- **بیش از ۱۰٬۹۰۰ کانال زنده:** شامل کانال‌های ایران و سراسر جهان (دسته‌بندی‌شده بر اساس ژانر، کشور، زبان و کیفیت).
- **رابط کاربری رسیور ماهواره‌ای:** نمایشگر دیجیتالی سون‌سگمنت زرد کهربایی، متر سیگنال و پینگ زنده، OSD کامل اطلاعات کانال.
- **پشتیبانی از ریموت کنترل و حالت تلویزیون (TV Mode):** کلیدهای میانبر کامل کیبورد و ریموت (تعویض کانال، شماره‌گیری مستقیم، ورود به لیست، علاقه‌مندی‌ها، تنظیم صدا).
- **پلیر قدرتمند HLS:** پخش روان با `hls.js` و پشتیبانی بومی Safari/iOS همراه با انتخاب دستی کیفیت، تصویر در تصویر (PiP)، و تمام‌صفحه.
- **علاقه‌مندی‌ها و تاریخچه:** ذخیره خودکار کانال‌های نشان‌شده و اخیراً دیده‌شده روی حافظه مرورگر (`localStorage`).
- **تحلیل‌گر پلی‌لیست درون‌مرورگری:** محاسبه وضعیت کانال‌های فعال/قطع، نمودار توزیع پینگ، سریع‌ترین کانال‌ها و بررسی آنلاین کانال‌ها مستقیم در مرورگر.
- **پشتیبانی از PWA و نصب آفلاین:** قابلیت نصب به عنوان اپلیکیشن مستقل روی اندروید، ویندوز، مک و تلویزیون هوشمند.
- **امکان افزودن پلی‌لیست دلخواه:** پشتیبانی از وارد کردن آدرس اینترنتی یا فایل M3U دلخواه مستقیم در بخش تنظیمات.

## 🚀 راهنمای راه‌اندازی روی GitHub Pages (کمتر از ۲ دقیقه)

1. در سایت [GitHub](https://github.com) وارد شوید و یک مخزن جدید (**New Repository**) بسازید (نام دلخواه، مثلاً `parto-tv`). مخزن می‌تواند Public یا Private باشد.
2. تمام محتویات پوشه‌ی `parto-tv-static` را به مخزن پوش (Push) کنید:
   ```bash
   git init
   git add .
   git commit -m "Initial static release"
   git branch -M main
   git remote add origin https://github.com/USERNAME/parto-tv.git
   git push -u origin main
   ```
3. وارد مخزن در گیت‌هاب شوید ← به بخش **Settings** بروید ← در منوی سمت چپ روی **Pages** کلیک کنید.
4. در بخش **Build and deployment**:
   - اگر از تب Actions استفاده می‌کنید: **Source** را روی **GitHub Actions** بگذارید (یک ورک‌فلو خودکار داخل پروژه هست که بدون هیچ تنظیمی سایت را منتشر می‌کند).
   - یا گزینه **Deploy from a branch** را انتخاب کنید، شاخه را روی `main` و پوشه را روی `/ (root)` بگذارید و **Save** را بزنید.
5. پس از حدود ۱ دقیقه، لینک اختصاصی شما آماده است:
   ```
   https://USERNAME.github.io/parto-tv/
   ```

## 🦊 راهنمای راه‌اندازی روی GitLab Pages

1. در [GitLab](https://gitlab.com) یک پروژه جدید بسازید.
2. فایل‌های این پوشه را پوش کنید:
   ```bash
   git init
   git add .
   git commit -m "GitLab Pages release"
   git branch -M main
   git remote add origin https://gitlab.com/USERNAME/parto-tv.git
   git push -u origin main
   ```
3. فایل آماده‌ی `.gitlab-ci.yml` که داخل پروژه قرار دارد، به صورت کاملاً خودکار پایپ‌لاین انتشار گیت‌لب را اجرا می‌کند.
4. پس از اتمام پایپ‌لاین (حدود ۱ دقیقه)، در بخش **Deploy** ← **Pages** لینک سایت شما نمایش داده می‌شود:
   ```
   https://USERNAME.gitlab.io/parto-tv/
   ```

## 💻 اجرای محلی (روی کامپیوتر یا شبکه خانگی)

برای اجرای محلی بدون نیاز به آپلود:
1. ترمینال را در پوشه‌ی پروژه باز کنید.
2. دستور زیر را با پایتون اجرا کنید:
   ```bash
   python -m http.server 8080
   ```
3. در مرورگر آدرس `http://localhost:8080` را باز کنید.
(یا از اکستنشن **Live Server** در VS Code استفاده کنید).

## 🛠 به‌روزرسانی پلی‌لیست‌ها با Python

اگر می‌خواهید لیست کانال‌ها را از فایل‌های جدید `.m3u` به‌روز کنید:
1. فایل‌های `.m3u` خود را در پوشه‌ی `playlists/` جایگزین کنید.
2. اسکریپت بیلد را اجرا کنید:
   ```bash
   python build.py
   ```
   این اسکریپت در کسری از ثانیه تمام کانال‌ها را تحلیل و فایل `data/channels.json` را بازتولید می‌کند.

## 📡 ساختار فایل‌ها

```
├── index.html                 # رابط کاربری اصلی وب‌اپلیکیشن
├── style.css                  # استایل‌های رسیور ماهواره‌ای، فونت وزیرمتن و ریسپانسیو
├── app.js                     # منطق کامل برنامه بدون وابستگی به سرور
├── sw.js                      # سرویس‌ورکر جهت نصب PWA و کش آفلاین
├── manifest.webmanifest       # مانیفست وب‌اپلیکیشن برای موبایل و تلویزیون
├── favicon.svg                # آیکون وکتور پرتو تی‌وی
├── icons/                     # آیکون‌های استاندارد PWA
├── vendor/hls.min.js          # کتابخانه پخش HLS به صورت محلی و آفلاین
├── data/
│   ├── channels.json          # پایگاه داده استاتیک فشرده‌ی ۱۰٬۹۰۰+ کانال
│   └── channels.json.gz       # نسخه فشرده با Gzip
├── playlists/
│   ├── ir.m3u                 # کانال‌های زنده ایران
│   ├── index.m3u              # کانال‌های زنده جهان
│   └── sources.json           # نام‌ها و ترتیب منابع
├── build.py                   # اسکریپت پایتون برای ساخت مجدد دیتابیس کانال‌ها
├── cloudflare-worker.js       # اسکریپت کمکی پروکسی رایگان Cloudflare (اختیاری)
├── .github/workflows/deploy.yml # تنظیمات انتشار خودکار GitHub Pages
├── .gitlab-ci.yml             # تنظیمات انتشار خودکار GitLab Pages
└── .nojekyll                  # جلوگیری از پردازش Jekyll در گیت‌هاب
```

## 🎮 کلیدهای میانبر کیبورد و ریموت کنترل

| کلید | عملکرد |
|---|---|
| **↑ / ↓** | تعویض کانال بعدی / قبلی (Zap) |
| **OK / Enter** | باز کردن لیست کانال‌ها / انتخاب کانال |
| **۰ تا ۹** | شماره‌گیری مستقیم کانال با نمایشگر LED |
| **← / →** | کاهش و افزایش صدا |
| **I** | نمایش مشخصات فنی استریم (بیت‌ریت، رزولوشن، بافر) |
| **Space** | نشان کردن کانال در علاقه‌مندی‌ها |
| **Esc / Back** | خروج از پلیر / بازگشت به فهرست |
| **M** | قطع / وصل صدا (Mute) |
| **F** | تمام‌صفحه (Fullscreen) |
| **Q** | منوی تغییر کیفیت ویدیو |
